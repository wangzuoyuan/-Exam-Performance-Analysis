# 02 · 数据模型蓝图

源：`backend/app/db/models.py`。SQLite + SQLAlchemy，`Base.metadata.create_all` 启动即建表（无 Alembic）。
**新增表自动建；改既有表列需一次性迁移脚本**（见 §5）。

## 1. 新增：身份层两表（复用教学版 06 设计）

### 1.1 `student_identity` — 人（跨学段身份）
```python
class StudentIdentity(Base):
    __tablename__ = "student_identity"
    id = Column(Integer, primary_key=True)
    display_name = Column(String, nullable=True)   # 展示名（取最近学段姓名）
    gender = Column(String, nullable=True)
    ext_key = Column(String, nullable=True, index=True)  # 预留：身份证/全国学籍号，默认不用
    note = Column(String, nullable=True)
    created_at = Column(DateTime, default=datetime.utcnow)
```
> **不要**用 `SubjectScore.xueji` 当身份键——实测它是 1/3/4 状态码，非唯一。

### 1.2 `student_alias` — 学号 ↔ 人
```python
class StudentAlias(Base):
    __tablename__ = "student_alias"
    id = Column(Integer, primary_key=True)
    identity_id = Column(Integer, ForeignKey("student_identity.id"), nullable=False)
    student_id = Column(String, nullable=False)        # 某学段的学号
    grade = Column(Integer, nullable=True)             # 该学号所属年级 1/2/3
    link_source = Column(String, nullable=False, default="name_confirmed")
        # name_confirmed / crosswalk / manual / ext_key
    created_at = Column(DateTime, default=datetime.utcnow)
    __table_args__ = (
        UniqueConstraint("student_id", name="uq_alias_student"),  # 一个学号只属一个人
        Index("idx_alias_identity", "identity_id"),
    )
```
- 一人多学号（高一一个、高二一个…）；一个学号唯一属一个人。
- **未链接的学号**：不强制每个学号都建 identity——读侧「查不到 alias 就把该学号当独立单人」。**未换届/未确认时系统退化为现状行为**（零配置可用，零回归）。

## 2. 改既有表：`class_roster` 加 `grade`（作业花名册支持换届）

现状：`class_roster` 主键 `student_id`，单一 `class_num`，**无年级**。换届后高二要用新学号建一份新名册，但高一名册（及其 `homework_record` 外键）要保留为历史。

```python
class ClassRoster(Base):
    student_id = Column(String, primary_key=True)  # 真实学号（当学段）
    name = Column(String, nullable=False)
    class_num = Column(Integer, nullable=True)
    grade = Column(Integer, nullable=True)          # 【新增】该名册行所属年级 1/2/3
    seat_no = Column(Integer, nullable=True)
    gender = Column(String, nullable=True)
    excluded = Column(Integer, nullable=False, default=0)
```
- 高一/高二名册**并存**（不同 `student_id`、不同 `grade`），`homework_record`/`special_record` 外键不破。
- **当前活动名册**：在 `homework_setting` 存 `active_grade`（默认取库内最大年级）。作业看板/排行/预警**只统计 `grade == active_grade` 的名册**——单年口径，不跨年混算（对应 01·D4）。
- 学生画像里的作业卡按**人并集**读（跨两个学号），见 03·§4。

## 3. 新增：`imported_history` — 隔离的导入高一成绩（对应 01·D5）

新转入学生的高一成绩来自外校/外班，**绝不能**进全年级排名/班均。单独存，只供该生趋势展示：

```python
class ImportedHistory(Base):
    """转入生导入的历史成绩。按 identity 挂，与正式 Exam/SubjectScore/TotalScore 完全隔离，
    不参与任何全年级排名 / 班均分 / 段位计算。仅学生画像趋势读取。"""
    __tablename__ = "imported_history"
    id = Column(Integer, primary_key=True)
    identity_id = Column(Integer, ForeignKey("student_identity.id"), nullable=False)
    grade = Column(Integer, nullable=False, default=1)   # 导入成绩的学段，一般=1
    exam_label = Column(String, nullable=True)           # 自填考试名，如「高一下期末(原校)」
    exam_seq = Column(Integer, nullable=True)            # 同生多场的排序
    kind = Column(String, nullable=False)                # subject / total
    subject = Column(String, nullable=True)              # kind=subject 时
    total_type = Column(String, nullable=True)           # kind=total 时（主三门/五门/+3/3+3）
    raw_score = Column(Float, nullable=True)
    grade_score = Column(Float, nullable=True)
    grade_percentile = Column(Float, nullable=True)
    xueji_rank = Column(Integer, nullable=True)
    __table_args__ = (Index("idx_imp_identity", "identity_id"),)
```
> 选择**独立表**而非给 `Exam` 加 `imported` 标记：避免改动所有「全年级排名/班均」查询去 `WHERE imported==0`，把污染风险压到零、改动面最小。学生画像端点把它**并进趋势**时打 `imported=True` 标记，前端用虚线/淡色区分。

## 4. 不动的表

`teacher`（保留 `target_class_highN`）、`exam`、`subject_score`、`total_score`、`class_average`、
`analysis_config`、`homework_record`、`special_record`、`student_note` —— 结构均不变。
（`student_note` / `homework_record` 仍按 `student_id` 存；跨学年「可见」靠读侧按人并集，不靠改表。）

## 5. 迁移脚本（一次性，幂等）

新建 `backend/app/db/migrate_homeroom.py`，参考既有 `homework/migrate.py` 风格：

1. `Base.metadata.create_all()` 建新表（`student_identity` / `student_alias` / `imported_history`）。
2. `class_roster` 加 `grade` 列：先 `PRAGMA table_info(class_roster)` 判断是否已有，再 `ALTER TABLE ... ADD COLUMN grade INTEGER`（幂等）。
3. **回填**：把现有 `class_roster` 行的 `grade` 按 `homework_setting` 里学期信息或人工指定补一个默认年级（一般是当前带的年级）；`homework_setting` 写入 `active_grade`。
4. **不自动并档**：身份层只建表，**存量学号一律不建 identity**——等换届向导确认或导对照表后才建链（无可靠锚点，自动并档会错）。
5. 用 `homework_setting.schema_version` 标记版本，避免重复 `ALTER` 报错。
6. 在启动路径 / `run.py init` 接入调用一次。

> 兼容性：迁移后、换届前，所有页面行为与现状一致（无 alias → 学号即独立人；`class_roster` 全部归到回填的那个 grade）。

## 6. 表关系总图

```
teacher ──target_class_highN──▶ (单年分析按 class_num 过滤，照旧)

student_identity ──1:N──▶ student_alias ──student_id──▶ ┐
                                                          ├─▶ SubjectScore / TotalScore (by student_id, 不变)
                                                          ├─▶ student_note      (by student_id, 读侧按人并集)
                                                          └─▶ class_roster(+grade)→ homework_record (按人并集 + 当前年级看板)
student_identity ──1:N──▶ imported_history (隔离, 仅画像趋势)
```
