# 04 · 前端改造蓝图

源：`frontend/src/`。Next 14 App Router + shadcn/ui + Recharts。布局由 `Shell.tsx` 接管
（新增页**不要**自带 header/max-w/min-h-screen/bg-slate-50）。改动集中在 3 处：换届向导、学生画像、学生检索。

## 0. 全局小改

- `lib/labels.ts`：新增 `formatStageHistory(aliases)` —— 把 `[{grade,class_num,student_id}]` 渲染成
  「高一(6)班·7250601 → 高二(3)班·7260315」的学段履历串。保留现有 `formatClassLabel/formatGradeLabel`。
- `Sidebar.tsx`：导航加入口「**升级换届**」（`/settings/rollover`）。底部「当前班级」改为显示
  `target_class_highN` 中**当前年级**那个班 + 「作业看板当前：高{active_grade}」。
- 首页 `/`：当 `teacher.has_pending_rollover` 为真时，顶部显示横幅
  「检测到高二成绩，部分学生学号已变更，去做升级换届以接续学情 →」。

## 1. 升级换届向导 `/settings/rollover`（核心新页）

把 03·§3 的 API 串成一条一次性工作流。建议 3 步式（shadcn `Tabs` 或步骤条）：

### 步骤 1 · 设定高二班 + 建名册
- 选目标年级（高二/高三）与行政班号（预填上传检测到的 `detected_class`）；写 `target_class_highN`。
- 建作业花名册（`POST /api/rollover/roster`）：
  - 「**从高二成绩派生**」（`from_scores`）：成绩已上传时一键拉该 `class_num` 全体。
  - 「**上传花名册 Excel / 粘贴清单**」：开学排班、成绩未出时用（含座号、性别）。

### 步骤 2 · 逐人判定（消费 `GET /api/rollover/preview`）
四态分区展示（shadcn `Table` + `Badge`），每态一组：

| 态 | 徽章 | 行内操作 |
|----|------|----------|
| `inherited` 已继承 | 绿「继承·已确认 / 继承·对照表」 | 「解除关联」 |
| `ambiguous` 同名待确认 | 黄「同名 N 个候选」 | 点开 `Dialog`：列高一候选（**高一行政班 / 最近主三门名次 / 高一学号**）→ 选「是某某」或「都不是·新学生」 |
| `new` 新学生 | 蓝「新」 | 「导入高一成绩」/「手动关联高一学号」 |
| `unmatched` 待补 | 灰「无成绩数据」 | 提示「等高二成绩上传 / 核对学号」 |
| `left_class` 离班（侧栏小卡） | 「高一在班·高二未见」 | 仅提示，无动作 |

- 顶部「**导入对照表**」按钮：上传/粘贴「高一学号↔高二学号」→ `POST /api/rollover/crosswalk`，回填后大批量学生直接进 `inherited`，显著减少逐人确认（对应「对照表为辅」）。
- 同名确认与对照表都落 `student_alias`；确认完点「完成」刷新 preview，`has_pending_rollover` 转假、横幅消失。

### 步骤 3 · 切换作业看板年级
- 一键「把作业看板切到高{N}」（`PATCH /api/rollover/active-grade`）。说明：历史高一缺交仍在学生画像可见，但看板/排行只看当前年级。

> **同名候选 Dialog 是体验关键**：候选项必须并排展示高一行政班 + 最近主三门名次 + 高一学号，让老师一眼辨认「是不是我高一带过的那个」。绝不提供「自动全部确认同名」按钮（避免错并档案）。

## 2. 学生画像 `/student/[id]`（学情继承的展示落点）

- **头部「学段履历」**：用 `identity.aliases` 渲染
  `高一(6)班 7250601 → 高二(3)班 7260315`；若仅一个学段则照常显示。
- **跨学段连贯趋势**：主三门/语数英趋势图本就按 `exam_sort_key` 跨年级排序——union 后高一段自动接上高二段。
  - 高一段与高二段用**不同底色块**（`ReferenceArea`）区分学段；趋势点 tooltip 标注「当年班级·当年学号」。
  - **导入的高一成绩**（`imported:true`）用**虚线 / 半透明点**画，图例标「导入·不计年级排名」。
- **新生入口**：若该生 `identity` 仅有高二、且无高一数据 → 趋势仅从高二起，画像头部显示
  「该生无高一记录，[导入高一成绩] / [关联高一学号]」按钮（调 `import-history` / `link`）。
- **档案卡 / 作业卡**：后端已按人并集读，高一谈话记录、高一缺交在高二画像直接可见，前端无需特殊处理（卡片标注记录发生的学段即可）。
- 「主三门班级排名」文案保留；口径已由后端按当年同班 peer 算，正确。

## 3. 学生检索 `/student`（按人去重）

现状：聚合所有 exam 的 students 前端搜索，班级列 `${class_num}班`，**同一人换号会出现两行**。改造：

1. 数据源换成 `GET /api/students`（03·§2.3），后端已**按人去重**并附当前班级/学号。
2. 列表每行显示**当前学段学号 + 当前班级**；行可展开看「历史学号」（高一 7250601 / 高二 7260315）。
3. 搜索按姓名 / 任一学号命中（后端或前端过滤均可）。
4. 概览卡「学生数」= 去重后的人数。

## 4. 作业花名册管理 `/homework/manage`（换届入口）

- 花名册页加「**升级换届**」按钮跳 `/settings/rollover` 步骤 1/3。
- 名册列表标注 `grade`，并显示「当前看板年级：高{active_grade}」；切换年级即换看到的名册。

## 5. 移动端与既有约定

- 沿用 `Shell.tsx` 响应式；向导表格窄屏用卡片视图（`md:hidden`）+ 桌面宽表（`hidden md:block`），同名候选 `Dialog` 窄屏全屏化。
- 颜色用 `brand-*`/`success`/`warning`/`danger` token；Recharts 内写颜色字符串。继承=`success`、同名待确认=`warning`、新生=`brand`、导入历史=半透明虚线。
- 缺考字段仍显示 `—`。`text-base`(16px) 防 iOS 聚焦缩放。

## 6. 前端测试 / 自检

- `npx tsc --noEmit` 通过（接口改动同步类型）。
- 端到端手测：绑高二班 → 建名册 → preview 四态 → 同名 Dialog 确认 1 人 → 导对照表批量继承 → 新生导入高一成绩 → 学生画像见跨学段趋势 + 学段履历 → 检索同一人只 1 行 → 切作业看板年级。
